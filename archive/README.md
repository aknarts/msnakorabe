# Archive of Original MŠ Na Korábě Website

**Source:** http://www.msnakorabe.cz/
**Archived:** 2026-02-13

This directory contains a complete archive of the original kindergarten website content,
downloaded as a backup in case the original hosting goes down.

## Contents

### html/
All 11 HTML pages from the original site, saved with descriptive filenames.

### images/
All images referenced across the site (logos, photos of school, garden, activities).

### documents/
All downloadable PDFs and documents:
- Enrollment forms (žádost o přijetí, evidenční list, kritéria)
- School rules (školní řád, dodatky)
- Various forms (late arrivals, medication agreements, proxy pickup)
- Budget documents (rozpočty, střednědobé výhledy)
- Nature school forms (školka v přírodě)
- GDPR documents
- Project documents (šablony OP JAK, potravinová pomoc)
